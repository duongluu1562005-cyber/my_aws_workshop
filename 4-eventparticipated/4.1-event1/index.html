Event 1

AWS CLOUD AND AI DAY HANOI 2026

  • Date: Tuesday, September 29, 2026
  • Main Event Location: JW Marriott Hotel Hanoi, Vietnam
  • Organizer: Amazon Web Services (AWS)
  • Participation Format: HCMC Watch Party organized by First Cloud AI Journey (FCAJ) in Ho Chi Minh City
  • Role: Watch Party Attendee

1. Event Introduction and Objectives

AWS Cloud and AI Day Hanoi 2026 was a technology event focusing on Cloud Computing, Artificial Intelligence (AI), Data Analytics, and modern application development.

The event brought together AWS experts, engineers, solution architects, and business representatives to share their knowledge, experiences, and practical technology solutions.

The main objectives of the event included:

  • Exploring the latest trends in Cloud Computing and AI.
  • Understanding how AI can support software development and workflow automation.
  • Learning about AWS solutions for data management, security, and resource optimization.
  • Gaining insights into building, deploying, and operating cloud-based systems.
  • Creating opportunities to learn from and connect with the technology community.

I participated in the event through the HCMC Watch Party, organized by the First Cloud AI Journey community in Ho Chi Minh City, where attendees followed the live broadcast from Hanoi.

4. Key Topics and Highlights

4.1. Keynote – What Does It Take to Solve Problems Everyone Says Are Impossible?

The opening keynote explored how technology can help individuals and businesses address challenges that may initially seem impossible to solve.

Key highlights:

  • Using AI Agents to support daily tasks and software development.
  • Modernizing existing systems through Cloud Computing.
  • Building scalable and reliable applications.
  • Ensuring security and reliability when deploying cloud-based solutions.

What I learned:

This session helped me understand that Cloud Computing and AI are not separate technologies. When combined, they can improve productivity, support innovation, and make business operations more efficient.

4.2. Building Software Like Never Before with Agentic AI

  • Time: 11:00
  • Presenter: AWS
  • Format: A session was available for the HCMC Watch Party.

This was one of the topics that interested me the most because it was directly related to software development.

The session introduced Agentic AI, which refers to AI systems capable of carrying out tasks based on specific goals rather than simply responding to questions like traditional chatbots.

Main discussion points:

  • How AI Agents can assist developers throughout the software development process.
  • Automating repetitive tasks such as code generation, testing, and information processing.
  • Integrating AI Agents into existing development workflows.
  • Understanding important considerations when applying AI to real-world projects.

What I learned:

I gained a better understanding of how AI can become a useful assistant for software developers.

However, developers still need to review AI-generated results, monitor system behavior, and make important decisions.

4.3. From Demo to Deployment: Solving Agentic AI’s Toughest Challenges

  • Presenters: Katalon and AWS

This topic focused on the challenges of transforming an AI application from an experimental demonstration into a system that can operate effectively in real-world environments.

Key challenges discussed:

  • Maintaining system stability and reliability.
  • Evaluating the accuracy of AI-generated results.
  • Protecting sensitive data and managing access permissions.
  • Monitoring and controlling AI Agent activities.

What I learned:

Building an AI application that works in a demonstration is only the first step.

For long-term use, the application must also be tested carefully, secured properly, and equipped with mechanisms to handle errors and unexpected situations.

4.4. Data Analytics and Building a Data Foundation for AI

Another important area covered during the event was data management and how organizations can use data to develop AI applications.

Featured topics:

  • Build an AI-ready Data Foundation: Preparing and organizing data for AI applications.
  • Data-Driven AI Agents for FSI: Applying data-driven AI Agents in financial services.
  • Amazon Quick Suite: Supporting information retrieval and analysis across multiple data sources.
  • VPBank’s Cloud Journey with Amazon Redshift: Sharing how VPBank developed its data platform using AWS.

Key highlights:

  • Organizing and managing data before using it in AI systems.
  • Connecting information from different platforms and systems.
  • Using AWS services for data storage and analytics.
  • Understanding how data supports better business decisions.

What I learned:

I realized that data plays a fundamental role in the development of AI applications.

If data is inaccurate, incomplete, or poorly organized, the results generated by AI systems may also be unreliable.

Therefore, building a strong data foundation is an important step before developing advanced AI solutions.

4.5. Modernizing Applications on AWS

The event also introduced solutions that help organizations modernize their existing software systems and improve application performance.

Featured topics:

  • Amazon EKS: Managing and deploying containerized applications.
  • Migrating a NestJS App from EC2 to EKS with GitOps: Exploring the migration of a NestJS application from Amazon EC2 to Amazon EKS.
  • From Monolith to Microservices: Transforming traditional monolithic applications into smaller, independent services.
  • AWS Transform: Using AI to support the modernization of .NET and SQL Server applications.

What I learned:

These topics helped me understand how businesses improve their systems to make deployment, maintenance, and scaling more manageable.

I also learned that not every application requires a complex architecture.

Choosing the right solution should depend on the actual requirements, size, and development goals of the project.

4.6. Cloud Security and AWS Cost Optimization

Besides AI and application development, the event also highlighted the importance of security and cost management when using AWS.

Featured topics:

  • AWS Security Agent: Supporting the identification and resolution of security issues during application development.
  • Workload Identity: Managing application identities and access permissions on AWS.
  • Amazon S3 Storage Classes: Selecting suitable storage options to optimize costs.
  • Amazon Bedrock Cost Control: Monitoring and managing the costs of AI services.
  • Multi-Agent Infrastructure Management: Using AI Agents to assist with infrastructure configuration and management.

Key lessons:

  • Applying appropriate access permissions based on user and application requirements.
  • Protecting data and applications deployed in cloud environments.
  • Selecting storage services based on how frequently data is accessed.
  • Monitoring AWS resources to avoid unnecessary expenses.

What I learned:

When developing an application on AWS, ensuring that the system functions correctly is not enough.

Security, performance, resource management, and operating costs must also be considered throughout the development and deployment process.

5. My Experience at the HCMC Watch Party

I attended AWS Cloud and AI Day Hanoi 2026 through the HCMC Watch Party organized by the First Cloud AI Journey community in Ho Chi Minh City.

Through the live broadcast from Hanoi, I had the opportunity to follow presentations about Cloud Computing, Artificial Intelligence, and practical technology solutions.

Among the topics presented, I was particularly interested in:

  • Software development using AI Agents.
  • Data management and analytics.
  • Modern application deployment on AWS.
  • Cloud security and cost optimization.

Participating in the Watch Party allowed me to explore knowledge beyond my university courses and gain a more practical understanding of the technologies being adopted by businesses.

It was also an opportunity to learn more about the AWS ecosystem and identify the technical skills that I should continue developing.

6. Knowledge and Skills Gained

After attending the event and reviewing the topics introduced, I gained several valuable insights.

6.1. A Better Understanding of Cloud Computing

I developed a clearer understanding of how AWS supports the deployment, storage, and management of applications.

Cloud Computing provides organizations with flexible options for building and scaling systems according to their needs.

6.2. Understanding the Role of AI Agents

I learned that AI Agents can support different stages of software development, including coding, testing, and workflow automation.

However, AI-generated results still require human supervision, verification, and appropriate access control to reduce errors.

6.3. Recognizing the Importance of Data

I understood that data quality, data sources, and data organization are essential when building AI applications.

A reliable data foundation directly contributes to the accuracy and effectiveness of AI systems.

6.4. Increasing My Awareness of Cloud Security

The event helped me recognize that security should not be considered only after an application has been completed.

Instead, security practices should be integrated into the system design, development, and deployment processes.

6.5. Understanding AWS Cost Management

I learned that using AWS services requires careful resource monitoring and cost management.

Choosing suitable configurations and tracking service usage can help avoid unnecessary expenses.

7. Future Learning and Practical Applications

The knowledge gained from the event provided me with a clearer direction for continuing my studies and hands-on practice with AWS.

In the future, I plan to focus on the following AWS services and technical areas:

  • Amazon S3: Practicing data storage and management.
  • Amazon Bedrock: Learning how to integrate AI capabilities into applications.
  • Amazon ECS and AWS Fargate: Exploring cloud-based application deployment.
  • AWS Security: Understanding access management and data protection.
  • AWS Cost Management: Monitoring cloud resources and controlling operational costs.

I also want to apply these concepts to practical projects, especially applications that combine Cloud Computing, Artificial Intelligence, and data processing.

Through hands-on exercises and small projects, I hope to strengthen my technical foundation and gain more experience working with AWS services.

8. Personal Reflection

AWS Cloud and AI Day Hanoi 2026 was a valuable learning experience for me.

Although I participated remotely through the HCMC Watch Party in Ho Chi Minh City, I still had the opportunity to explore a wide range of technology topics and learn about solutions being applied in real-world environments.

The topics that impressed me the most were the potential of AI Agents in software development and the role of AWS in building, deploying, and operating modern applications.

The event helped me expand my knowledge, better understand the technical skills I need to develop, and become more motivated to continue learning and practicing AWS.

Overall, this experience encouraged me to explore Cloud Computing and AI more deeply and apply what I have learned to future projects.
