DEPLOY INTEGRATIONS

integrations.yaml configures GuardDuty Malware Protection for S3 PDF scanning, EventBridge result delivery, SQS and a DLQ. It also defines IAM and queue policies, CloudWatch alarms and optional SNS email notification resources.

Create the stack

  1. In us-east-1, select CloudFormation → Create stack → With new resources (standard) and upload integrations.yaml.

📸 Capture the selected filename.

Upload integrations.yaml

  1. Name the stack tindy-integrations. Set MediaBucketName from Foundation Outputs and provide the alarm recipient in ScanAlarmEmail. Leave AlbMetricLoadBalancer and AlbMetricTargetGroup empty until Runtime creates the new ALB and target group, then update both dimensions through a change set.

📸 Capture the stack name and parameters. Review email visibility before publishing.

Integrations parameters

  1. Add tags Project=Tindy, Environment=tindy, Owner=TindyTeam. Keep Express mode disabled and rollback enabled, acknowledge IAM capabilities, review and create the stack.
  2. Wait for CREATE_COMPLETE and record GuardDutyProtectionPlanArn and GuardDutyQueueUrl from Outputs for Runtime.
  3. Under GuardDuty → Malware Protection for S3, verify the new plan is Active, tagging is enabled and prefixes include certificates/pdf/ and ai-input/pdf/.
  4. For the configured email, confirm the SNS subscription from its email and verify the confirmed state in SNS.

📸 Capture completed stack status, Outputs, the Active protection plan and confirmed subscription.
