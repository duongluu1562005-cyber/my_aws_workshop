During the **First Cloud AI Journey (FCAJ)** internship program, I had the opportunity to explore cloud computing through learning materials and hands-on tutorials on **Amazon Web Services (AWS)**.

The learning activities were organized into **12 weeks, starting on September 14, 2026**, followed by a period of reviewing and completing the internship report. During this time, I focused on learning fundamental AWS concepts, exploring commonly used services, managing cloud resources, understanding system security, and monitoring costs in a cloud environment.

In addition to studying theoretical concepts, I referred to hands-on tutorials, took notes, and summarized the knowledge I gained to prepare my internship report. The learning content focused on common AWS services, ranging from fundamental concepts to tools that support system deployment, management, and security in the cloud.

The following sections summarize the learning activities and tasks for each week:

**Week 1:** [Introduction to AWS and Cloud Computing Fundamentals](1.1-week1/)

**Week 2:** [Introduction to User Management and Access Control with AWS IAM](1.2-week2/)

**Week 3:** [Introduction to Virtual Servers with Amazon EC2](1.3-week3/)

**Week 4:** [Introduction to Cloud Networking with Amazon VPC](1.4-week4/)

**Week 5:** [Introduction to Data Storage with Amazon S3 and Amazon RDS](1.5-week5/)

**Week 6:** [Resource Monitoring and Cost Management with Amazon CloudWatch and AWS Budgets](1.6-week6/)

**Week 7:** [Introduction to Data Backup and Application Security on AWS](1.7-week7/)

**Week 8:** [Introduction to AWS Lambda and Container Technologies](1.8-week8/)

**Week 9:** [Introduction to Deployment and Automation with AWS CloudFormation](1.9-week9/)

**Week 10:** [Introduction to Data Analytics and AI Services on AWS](1.10-week10/)

**Week 11:** [AWS Cost Optimization and Knowledge Review](1.11-week11/)

**Week 12:** [Knowledge Summary and Internship Report Finalization](1.12-week12/)

The learning content was primarily based on [AWS Cloud Journey](https://cloudjourney.awsfcaj.com/) and official AWS documentation.
