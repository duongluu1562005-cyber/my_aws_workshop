# Introduction to Data Analytics and AI Services on AWS

### Weekly Objectives

- Understand how AWS supports data storage and analytics.
- Become familiar with Data Lakes and Amazon Athena.
- Learn about Artificial Intelligence (AI), Machine Learning (ML), and their applications on AWS.
- Explore Amazon SageMaker and how AWS supports the development of AI models.

### Learning Outcomes

- Understood that Data Analytics involves processing and analyzing data to discover useful information and insights.
- Learned that Data Lakes can store different types of data and that Amazon S3 can be used as the storage foundation for a Data Lake.
- Became familiar with Amazon Athena and how SQL can be used to query data stored in Amazon S3.
- Understood the fundamental concepts of Artificial Intelligence (AI) and Machine Learning (ML).
- Learned about common AI applications such as image recognition, natural language processing, and predictive analytics.
- Became familiar with Amazon SageMaker and the basic steps involved in building Machine Learning models.
- Understood how data storage, analytics, and AI services can work together on AWS.
