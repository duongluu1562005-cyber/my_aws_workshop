# Introduction to AWS and Cloud Computing Fundamentals

### Weekly Objectives

- Become familiar with the First Cloud AI Journey (FCAJ) internship program and its learning resources.
- Understand cloud computing concepts and the main categories of AWS services.
- Explore AWS accounts, AWS Management Console, and AWS Global Infrastructure.
- Learn about AWS cost management and the structure of internship reports on GitHub.

### Learning Outcomes

- Became familiar with the FCAJ internship program, its regulations, and learning materials provided by AWS Study Group.
- Understood the fundamentals of cloud computing and the functions of the main AWS service categories:
  - **Compute:** Provides computing resources and virtual servers.
  - **Storage:** Stores files and data.
  - **Networking:** Manages network connectivity.
  - **Database:** Manages and stores structured data.
- Learned how to find and access services through the AWS Management Console.
- Understood AWS Regions, Availability Zones, and how AWS organizes its data centers.
- Learned about AWS account security and Multi-Factor Authentication (MFA).
- Gained a basic understanding of AWS pricing, AWS Credits, and cost monitoring using AWS Budgets.
