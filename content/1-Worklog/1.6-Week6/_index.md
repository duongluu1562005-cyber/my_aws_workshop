# Resource Monitoring and Cost Management with Amazon CloudWatch and AWS Budgets

### Weekly Objectives

- Understand Amazon CloudWatch and how to monitor AWS resources.
- Become familiar with CloudWatch Metrics, Logs, and Alarms.
- Learn about AWS Budgets and how to manage AWS usage costs.
- Explore how to monitor system performance and receive alerts when needed.

### Learning Outcomes

- Understood that Amazon CloudWatch is used to monitor AWS resources and applications.
- Became familiar with the main CloudWatch features:
  - **Metrics:** Monitor performance indicators such as CPU utilization and network traffic.
  - **Logs:** Collect and view system and application logs.
  - **Alarms:** Monitor metrics and trigger alerts when configured conditions are met.
  - **Dashboards:** Visualize metrics and monitoring data using charts.
- Learned how to view EC2 performance metrics through CloudWatch tutorials.
- Understood how CloudWatch Alarms help detect changes that require attention.
- Learned that AWS Budgets is used to monitor AWS costs and resource usage.
- Became familiar with the steps for creating budgets, configuring alert thresholds, and receiving email notifications.
- Understood that AWS Budgets provides cost alerts but does not automatically prevent all charges from exceeding the configured budget.
